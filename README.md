# SIOT US TikTok Shop - 업무 대시보드

SIOT 브랜드의 미국 틱톡샵 팀을 위한 실시간 업무 관리 대시보드입니다.

## 🎯 주요 기능

- 📊 KPI 현황 (실시간 Google Sheets 동기화)
- 📧 메일 시딩 상세 (신규/킵고잉/VIP 그룹)
- 🌐 메일 이외 시딩 (OC, TC, 디스코드)
- 👥 업무 분담 (팀원별 역할 및 체크리스트)
- 🔗 빠른 링크 (회의록, 대시보드, 소통 시트)

## 🚀 사용 방법

### Google Sheet 연동

1. 대시보드 우상단 ⚙️ 버튼 클릭
2. Sheet ID 입력
3. "연동하기" 클릭

### GitHub Pages 배포

1. GitHub 저장소 생성 (siot-us-shop-dashboard)
2. index.html, README.md 업로드
3. Settings → Pages 활성화

## 📋 필요한 Google Sheet 탭

1. **KPI** - 주차, 시작일, 종료일, GMV, ROI, 메일시딩영상, 전체영상
2. **메일시딩** - 그룹, 주차, 영상수, GMV, 누적영상, 누적GMV, 비고
3. **메일이외** - 채널, 주차, 영상수, GMV, 누적영상, 누적GMV, 담당자, 비고
